# คู่มือนำ Stock Platform ขึ้น AWS (ทีละขั้น)

เป้าหมาย: เว็บเปิดตลอด 24 ชม. เข้าจากอุปกรณ์/เครือข่ายไหนก็ได้ โดยไม่ต้องเปิดคอมตัวเอง

## ภาพรวม
```
ผู้ใช้ ──► (พอร์ต 80/443) nginx ──► Streamlit (127.0.0.1:8501, รันเป็น service ชื่อ stockplatform)
                                   └─ ข้อมูล: /opt/stock-platform/data/ (ฐานข้อมูลผู้ใช้, ข้อมูลหุ้นลาว, แคช SEC)
```

## ขั้นที่ 1 — สมัคร AWS (ทำเอง)
1. สมัครที่ aws.amazon.com (ต้องใช้อีเมล เบอร์โทร และบัตรเครดิต/เดบิต)
2. ตั้งการแจ้งเตือนค่าใช้จ่าย: Billing → Budgets → สร้างงบเช่น 10 ดอลลาร์ต่อเดือน แจ้งเตือนทางอีเมล

## ขั้นที่ 2 — สร้างเครื่องบน Lightsail
1. เปิด lightsail.aws.amazon.com → **Create instance**
2. Region: **Singapore** (ใกล้ลาวที่สุด)
3. Platform: **Linux/Unix**, Blueprint: **OS Only → Ubuntu 24.04 LTS**
4. Plan: **RAM 2GB** แนะนำ (1GB ใช้ได้แต่ช้ากว่า — สคริปต์สร้าง swap ให้) ราคาเปลี่ยนได้ ดูที่หน้าสร้างเครื่อง
5. ตั้งชื่อเครื่อง เช่น `stock-platform` → Create
6. แท็บ **Networking** ของเครื่อง:
   - **Attach static IP** (กัน IP เปลี่ยนเวลารีสตาร์ต)
   - **IPv4 Firewall**: เพิ่มกฎ **HTTP (80)** และ **HTTPS (443)** (SSH 22 มีให้แล้ว)

## ขั้นที่ 3 — อัปโหลดและติดตั้ง
1. กดไอคอน **Connect using SSH** (เทอร์มินัลในเบราว์เซอร์)
2. อัปโหลด `stock-platform.zip` (ปุ่มลูกศรอัปโหลดบนหน้าต่าง SSH) แล้วพิมพ์:
```bash
sudo apt-get install -y unzip
unzip -q stock-platform.zip -d stock-platform
cd stock-platform
sudo bash deploy/setup_ubuntu.sh
```
3. รอ 3–6 นาที จนเห็น `✅ ติดตั้งสำเร็จ` พร้อมที่อยู่เว็บ → เปิดในเบราว์เซอร์

## ขั้นที่ 4 — ครั้งแรกหลังเว็บขึ้น
- ฐานข้อมูลผู้ใช้ว่างเปล่า → กด **สมัครสมาชิก** สร้างบัญชีของคุณ
- โครงสร้างรายได้ของหุ้นสหรัฐฯ: ต้องใส่อีเมลติดต่อ SEC ที่การ์ดโครงสร้างรายได้ (แท็บงบการเงิน) หนึ่งครั้ง
- ข้อมูลหุ้นลาวที่เตรียมไว้แล้วอยู่ใน zip เว็บจะอัปเดตเองทุก 6 ชม. (ถ้า LSX ยอมให้เซิร์ฟเวอร์ AWS เข้าถึง)

## (ไม่บังคับ) ใส่โดเมนและ HTTPS
1. ซื้อโดเมน แล้วตั้ง DNS รายการ **A** ชี้ไปที่ Static IP
2. รันซ้ำ: `sudo bash deploy/setup_ubuntu.sh ชื่อโดเมน.com อีเมลของคุณ`

## งานประจำที่ใช้บ่อย
| ต้องการ | คำสั่ง (ใน SSH) |
|---|---|
| ดู log เว็บ | `sudo journalctl -u stockplatform -f` |
| รีสตาร์ตเว็บ | `sudo systemctl restart stockplatform` |
| อัปเดตโค้ด | อัปโหลด zip ใหม่ แตกทับ แล้วรัน `sudo bash deploy/setup_ubuntu.sh` ซ้ำ (ฐานข้อมูลผู้ใช้ไม่หาย) |
| สำรองฐานข้อมูล | คัดลอก `/opt/stock-platform/data/app.db` ออกมาเก็บ |

## ค่าใช้จ่ายและความปลอดภัย
- ค่าเครื่องคิดรายเดือนแบบเหมาจ่าย **หยุดคิดเฉพาะเมื่อลบเครื่อง** (Stop ไม่พอ) ถ้าเลิกใช้ ให้ลบ instance และ static IP
- ใครรู้ลิงก์ก็สมัครบัญชีได้ ถ้าไม่ต้องการให้คนแปลกหน้าใช้ ให้ไม่เผยแพร่ลิงก์ หรือแจ้งผมให้เพิ่มระบบปิดการสมัคร
- ห้ามแชร์ไฟล์กุญแจ SSH หรือรหัสผ่าน AWS

## ข้อควรรู้เรื่องข้อมูลหุ้น
- หุ้นสหรัฐฯ/ไทยดึงจาก Yahoo Finance — Yahoo มักจำกัดการดึงจาก IP เซิร์ฟเวอร์คลาวด์ ราคาอาจโหลดไม่ขึ้นเป็นช่วงๆ
- หุ้นลาวดึงจาก lsx.com.la — ยังไม่ทราบว่าอนุญาตจาก IP ต่างประเทศหรือไม่ ถ้าดึงไม่ได้ เว็บใช้ข้อมูลที่แนบไปใน zip ต่อไป
