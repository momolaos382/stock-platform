# ข้อความสำหรับวางในแชท Claude ที่ควบคุมเบราว์เซอร์ AWS ได้

วิธีใช้: แนบไฟล์ `stock-platform.zip` ในแชทนั้น แล้วคัดลอกข้อความในกรอบด้านล่างไปวาง

---

ฉันมีเว็บแอปชื่อ **Stock Platform** (Python + Streamlit) ต้องการนำขึ้น **AWS** ให้เข้าใช้งานได้ผ่านอินเทอร์เน็ตจากทุกอุปกรณ์ โดยไม่ต้องเปิดคอมฉันไว้

**ไฟล์ที่แนบ:** `stock-platform.zip` คือโปรเจกต์ทั้งหมด ข้างในมีโฟลเดอร์ `deploy/` ที่เตรียมไว้แล้ว:
- `deploy/setup_ubuntu.sh` — สคริปต์ติดตั้งอัตโนมัติสำหรับ Ubuntu 22.04/24.04 (ติดตั้ง Python, nginx, ตั้ง systemd service ให้เว็บเปิดเองและเปิดใหม่เองถ้าล่ม, ตั้ง nginx ให้รองรับ websocket ของ Streamlit)
- `deploy/DEPLOY_TH.md` — คู่มือทีละขั้น (ภาษาไทย)
- `requirements.txt`, `app.py`, `core/`, `views/`, `static/`, `data/` — ตัวโปรเจกต์

**สิ่งที่อยากให้ทำ (ผ่านเบราว์เซอร์ AWS Console):**
1. สร้างเครื่อง **AWS Lightsail** (Linux/Unix → OS Only → Ubuntu 24.04 LTS) ภูมิภาค **Singapore (ap-southeast-1)** ขนาด **RAM 2GB** (หรือ 1GB ก็ได้ถ้าราคาถูกกว่าเยอะ — สคริปต์สร้าง swap ให้เอง)
2. เปิดพอร์ต **22, 80, 443** ในไฟร์วอลล์ (Networking) และสร้าง **Static IP** ผูกกับเครื่อง กัน IP เปลี่ยนเมื่อรีสตาร์ต
3. อัปโหลด `stock-platform.zip` ขึ้นเครื่อง (ใช้ Browser-based SSH ของ Lightsail ที่มีปุ่มอัปโหลดไฟล์ หรือทางอื่นที่สะดวก) แล้วแตก zip
4. รัน `sudo bash deploy/setup_ubuntu.sh` ในโฟลเดอร์ที่แตก (ถ้ามีโดเมนแล้ว: `sudo bash deploy/setup_ubuntu.sh ชื่อโดเมน อีเมล` เพื่อใส่ HTTPS)
5. ทดสอบว่าเปิด `http://<Static IP>` แล้วเห็นหน้า login และกด **สมัครสมาชิก** กับ **เข้าสู่ระบบ** ได้ จากนั้นแจ้ง URL กลับมา

**ข้อกำหนดสำคัญ:**
- **ก่อนสร้างหรือซื้ออะไรที่มีค่าใช้จ่าย ให้บอกชื่อบริการ ขนาดเครื่อง และราคาต่อเดือนที่เห็นบนหน้าจอ แล้วรอฉันยืนยันก่อนทุกครั้ง**
- ถ้าต้องล็อกอิน AWS, กรอกข้อมูลบัตร, ยืนยัน OTP/2FA ให้หยุดและบอกฉันทำเอง อย่ากรอกรหัสผ่านหรือข้อมูลบัตรแทน
- ไม่ต้องแก้โค้ดของเว็บ ถ้าสคริปต์ล้มเหลวให้อ่านข้อผิดพลาด (`sudo journalctl -u stockplatform -n 80 --no-pager`) แล้วรายงานฉัน
- อย่าลบหรือเขียนทับอะไรบน AWS ที่มีอยู่แล้วในบัญชีฉัน
- สร้างเสร็จแล้วสรุปให้ฉัน: URL, ราคาต่อเดือน, วิธีดู log, วิธีรีสตาร์ต และวิธีลบเครื่องทั้งหมดถ้าไม่ใช้แล้ว (เพื่อไม่ให้เสียเงินต่อ)

**หมายเหตุ:** ฐานข้อมูลผู้ใช้จะว่างเปล่าในเครื่องใหม่ ฉันจะสมัครบัญชีเองหลังเว็บขึ้นแล้ว
